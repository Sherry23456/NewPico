# 守望稻田 · 虫情守护 —— 生态科普 VR 小游戏

> 作品主线：水乡农场（种地 → 收获 → 卖粮）+ 虫情守护小游戏（生态科普 + 数据报告）。
> 由课后作业《锤锤乐》打地鼠迭代而来：**"炸弹不能敲"的抑制判断机制反转为"益虫不能拍"的生态保护教育点**。

## 一、怎么进游戏

1. 打开 `Assets/Scenes/Farm.unity`，直接 Play（场景已由 `Farm/M1` + `Farm/M3` 搭好）。
2. **全场只有一个任务：虫情大搜查**（种田交互、NPC 功能、自动卖货已全部退役，禾伯是背景板）：
   - **头顶任务栏**（跟随视角）：游戏说明 + 「开始搜查」按钮；搜查中自动收起不挡视线
   - 田边架子拿起**虫情拍**（手柄侧握键）
   - 点头顶「开始搜查」/ 敲**虫情锣** / PC 按 P 开局
   - 3 秒倒计时 → **害虫 14 只 + 益虫 5 只随机藏进 6 块田的植株间**（位置随机、轻微摇摆提示活物）
   - **规定时间 90 秒内**找到并拍掉全部害虫；拍到益虫（青蛙/瓢虫/蜜蜂）误伤扣分并弹科普知识卡
   - 结算告示牌出**守护报告**：找到明细/漏找/误伤/保护/找到率/平均查找耗时/S-A-B-C 评级/历史对比/金币经验，并随机补一张知识卡
3. 教育立意：模拟真实农事"田间查虫"（病虫监测）——学会**观察、辨识害虫与益虫**，理解生态防治，而不是无脑敲击

## 二、系统机制（答辩技术点）

| 答辩问题 | 回答落点 |
|---|---|
| 从游戏怎么变成"教育应用"？ | 玩法原型是农事"田间查虫"：放大田块走进植株间观察搜虫（观察力训练）；"炸弹不能敲"反转为"益虫不能拍"（生态保护）；误伤即弹知识卡 |
| 有没有数据支撑？ | `FarmPestLog`：每轮记录找到/漏找/误伤/保护/找到率/平均查找耗时，JSON 持久化，一键导出 CSV 供教师/研究人员分析 |
| 难度怎么设计的？ | **自适应难度**：提前找完且剩时 ≥30s → 下轮虫 +2、限时 −10s；漏找 ≥4 → 虫 −2、限时 +10s（实测两轮间 14→12 生效） |
| 性能怎么保证？ | 复用 `PrefabPool` 对象池（虫子全程零 Destroy）；装饰植株/虫子模板全部编辑期生成、运行期只取用 |
| 和农场主线什么关系？ | 搜查奖励金币（`FarmEconomy.AddCoins`）+ 经验（`FarmProgress`），反哺买化肥/升级解锁；田块就是同一批 `FarmPlot`，种田与查虫同一片地 |
| 场景怎么维护？ | 全部由编辑器菜单生成：`Farm/M1` 一键搭建（含本玩法），`Farm/M3` 单独增量重建（幂等） |

## 三、文件地图

- 运行时：`Assets/Farm/Scripts/FarmPest*.cs`（Variant/Pest/Swatter/Manager/UI/Log 六件套）
- 虫子模型：`Assets/Farm/Models/Insects/*.glb`（poly.pizza 低模，来源与授权见同目录 `credits.txt`，CC-BY 已署名）；搭建器 GLB 优先、缺失时退回程序化球体兜底
- 搭建：菜单 `Farm/M3 添加守望稻田小游戏`（幂等增量，重建 `PestGameRoot`）；`Farm/M1` 一键搭建时自动包含
- 数据：`Application.persistentDataPath/farm_pest_log.json`；CSV 导出为 `farm_pest_report.csv`
